# Saurabh Kumar Sunny — Frontend portfolio

Static frontend engineering portfolio. The published page is in `site/index.html`.

GitHub Actions deploys `site/` to GitHub Pages on a push to `main`. Set the repository's Pages source to **GitHub Actions**. The workflow deploys to the `github-pages` environment.

The public site uses email for resume requests. A PDF containing a personal phone number is deliberately excluded from this public repository.
